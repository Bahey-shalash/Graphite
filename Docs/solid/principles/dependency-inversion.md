# Dependency inversion (DIP)
Snapshot: b13dec3 (main, 2026-10-18).

Scope: every `DIP-*` finding of the twelve area audits and the cross-cutting audit (52 findings: 4 High, 27 Medium, 21 Low, from [findings-index.md](../findings-index.md)), checked against the code of the snapshot. In Swift terms the principle here means: models, sessions and views depend on values and narrow capabilities they are given; the app target alone decides which concrete adapter (disk, `UserDefaults`, network, WebKit, AVFoundation, keychain, clock) sits behind them.

**App-wide verdict: Weak.** The module graph points the right way and the seams that exist (the styling port, the capture source, the speech renderer, the runtime transport, the place store) are sound; but the app has no composition root, so wiring is decided inside models and views by 13 workspace property initializers, 15 `UserDefaults = .standard` defaults, 3 `URLSession = .shared` defaults, 11 singletons and 26 mutable statics. As a result no workspace, plugin host, canvas, Read Aloud session or Pencil surface can be built in a test without the developer's real preferences, real folders and process-global state.

## 2. Systemic patterns across the whole app

Ordered by cost: data-safety and testability first, then determinism, then direction.

### 2.1 No composition root: models and views construct their own I/O collaborators

**What it is.** Concrete adapters are created where they are used: in stored-property initializers of `@Observable` models, inside methods, in SwiftUI `@State` defaults, and in default arguments. Nothing above them can substitute a fake, a private defaults suite or a different writer.

**Where.** [DIP-ARCH-01](../cross-cutting/architecture.md#dip-arch-01-there-is-no-composition-root-the-workspace-constructs-its-own-io-collaborators-inside-swiftui-state), [DIP-SHELL-01](../areas/shell.md#dip-shell-01-workspacemodel-constructs-its-own-io-collaborators-so-no-test-can-isolate-it), [DIP-PLUGIN-01](../areas/plugin.md#dip-plugin-01-the-host-constructs-its-io-collaborators-and-reads-userdefaultsstandard), [DIP-PLUGIN-02](../areas/plugin.md#dip-plugin-02-default-arguments-construct-network-sessions-and-the-network-paths-have-no-tests), [DIP-LECTURE-03](../areas/lecture.md#dip-lecture-03-default-arguments-and-inline-constructors-create-io-collaborators), [DIP-VOICE-02](../areas/voice.md#dip-voice-02-initializers-construct-io-collaborators-in-default-arguments), [DIP-INK-04](../areas/ink.md#dip-ink-04-io-adapters-are-built-inline-and-by-default-arguments), [DIP-READING-01](../areas/reading.md#dip-reading-01-the-reading-builder-and-image-cache-construct-their-own-file-services), [DIP-EDITOR-02](../areas/editor.md#dip-editor-02-ui-types-construct-file-readers-and-depend-on-the-application-root), [DIP-BASES-01](../areas/bases.md#dip-bases-01-the-ui-model-performs-file-system-io-and-builds-its-own-collaborators), [DIP-BASES-03](../areas/bases.md#dip-bases-03-omitting-the-provider-silently-changes-semantics), [DIP-VAULT-01](../areas/vault.md#dip-vault-01-logic-constructs-its-own-writer-and-reaches-the-file-system-and-clock-directly), [DIP-VAULT-02](../areas/vault.md#dip-vault-02-the-indexs-cache-folder-is-chosen-inside-the-database-type). Systemic in SHELL, ARCH, PLUGIN, LECTURE, VOICE, INK, READING, EDITOR, BASES, VAULT (10 of 13 documents).

**Cost.**
- No test can isolate the workspace: tests snapshot and restore every `Graphite*` key of the real `UserDefaults.standard` and still leak the unprefixed ones (DIP-SHELL-01); the hosted tests write the app's own defaults domain and keychain (DIP-PLUGIN-01).
- The plugin installer's release selection, identifier checks and size cap ship with no test, because the network is a default argument (DIP-PLUGIN-02).

- Construction runs again whenever SwiftUI re-creates the `@State` default or the scene value, building a recorder, plugin host and speech observer each time (DIP-ARCH-01).

**Shared fix direction.** One `AppEnvironment` built once in `GraphiteApp.init` (the app target is the composition root); `WorkspaceModel.init(environment:)`, `CommunityPluginHost.init(deviceStorage:runtimeFactory:)` and every session initializer take their collaborators without defaults; per-vault adapters come from a `VaultOpener` the environment provides. Views receive the workspace from the scene and never construct it. Rules DIP 1, DIP 2.

### 2.2 Persisted device state is reached directly, with no owner

**What it is.** Preferences, per-vault memory and UI choices are read and written through `UserDefaults.standard`, `@AppStorage("literal")` and static readers, from models, commands, gesture code and views. Key names are declared beside each use. Commands use defaults to move views (a message bus).

**Where.** [DIP-ARCH-03](../cross-cutting/architecture.md#dip-arch-03-persisted-device-state-has-no-owner-about-91-key-names-four-naming-schemes-three-access-paths), [DIP-ARCH-04](../cross-cutting/architecture.md#dip-arch-04-userdefaults-is-used-as-a-message-bus-between-commands-and-views), [DIP-SHELL-02](../areas/shell.md#dip-shell-02-per-vault-device-state-is-written-to-userdefaultsstandard-under-five-concatenated-key-families-in-five-files), [DIP-SHELL-03](../areas/shell.md#dip-shell-03-model-code-and-command-code-write-view-owned-storage-keys-two-keys-are-typed-as-string-literals-in-several-files), [DIP-READING-03](../areas/reading.md#dip-reading-03-folds-and-inspector-choices-are-stored-through-userdefaultsstandard-from-feature-code), [DIP-CANVAS-01](../areas/canvas.md#dip-canvas-01-device-preferences-are-read-from-userdefaultsstandard-inside-the-session-and-views), [DIP-INK-03](../areas/ink.md#dip-ink-03-preferences-are-read-from-userdefaultsstandard-inside-gesture-and-drawing-code), [DIP-PLUGIN-01](../areas/plugin.md#dip-plugin-01-the-host-constructs-its-io-collaborators-and-reads-userdefaultsstandard), [DIP-VOICE-02](../areas/voice.md#dip-voice-02-initializers-construct-io-collaborators-in-default-arguments). Systemic in ARCH, SHELL, READING, CANVAS, INK, PLUGIN, VOICE.

**Evidence.**

- Per-vault keys concatenated in place: `"GraphiteExpandedFolders." + uuid` ([WorkspaceModel.swift:27-29](../../../Sources/GraphiteUI/WorkspaceModel.swift#L27-L29)), `"GraphiteFolds." + uuid` with the whole vault's fold dictionary read and rewritten on each change ([WorkspaceFolds.swift:7-31](../../../Sources/GraphiteUI/WorkspaceFolds.swift#L7-L31)), `"GraphiteCommunityPluginsTurnedOn." + uuid` ([CommunityPluginHost.swift:287-318](../../../Sources/GraphiteUI/CommunityPluginHost.swift#L287-L318)).

- The command palette writes `"GraphiteInspectorPanel"` and `SidebarPanelSettingKey.panel` to move views ([WorkspaceCommands.swift:71](../../../Sources/GraphiteUI/WorkspaceCommands.swift#L71), [:82](../../../Sources/GraphiteUI/WorkspaceCommands.swift#L82), [:89](../../../Sources/GraphiteUI/WorkspaceCommands.swift#L89)); the inspector reads the same literal through `@AppStorage` ([MarkdownPane.swift:891](../../../Sources/GraphiteUI/MarkdownPane.swift#L891)).

**Cost.**
- Removing a vault leaves its folded-heading records, which name its notes, on the device (BUG-SHELL-02, BUG-ARCH-06); Read Aloud positions are global, so a same-named note in another vault resumes at the wrong place (BUG-ARCH-07).
- Navigation intent is invisible to the model layer and to tests; every write to any key wakes every canvas (DIP-ARCH-04).

Panels are moved by model intents; only a choice's owner writes it. `DocumentPlaceStore` is the template (section 4). Rules DIP 5, DIP 6, DIP 7.

**What it is.** Shared services and caches are reached through `Type.shared` or static stored properties from views, coordinators and Core, instead of being passed in. Correctness then depends on exactly one workspace per process, which nothing enforces and which tests break.

Rules DIP 3, DIP 4, DIP 12.

### 2.4 Time, time zone and randomness are read inline

**What it is.** Decisions read `Date()`, `.now`, `ContinuousClock.now`, `systemUptime`, `TimeZone.current` or a random source themselves, or take them as default arguments, instead of receiving `now`, a calendar or a generator.

**Where.** [DIP-SHELL-05](../areas/shell.md#dip-shell-05-logic-reads-the-wall-clock-directly), [DIP-EDITOR-03](../areas/editor.md#dip-editor-03-logic-reads-the-platform-clock-devices-and-application-objects-directly), [DIP-INK-05](../areas/ink.md#dip-ink-05-wall-clock-and-system-uptime-are-read-in-editing-logic), [DIP-LECTURE-04](../areas/lecture.md#dip-lecture-04-logic-reads-clocks-directly), [DIP-CANVAS-04](../areas/canvas.md#dip-canvas-04-timing-uses-the-real-clock-and-real-sleeps-in-session-logic), [DIP-VOICE-04](../areas/voice.md#dip-voice-04-the-cache-uses-the-wall-clock-and-the-file-system-directly-and-its-actor-is-untested), [DIP-VAULT-01](../areas/vault.md#dip-vault-01-logic-constructs-its-own-writer-and-reaches-the-file-system-and-clock-directly), [DIP-BASES-01](../areas/bases.md#dip-bases-01-the-ui-model-performs-file-system-io-and-builds-its-own-collaborators), [DIP-BASES-02](../areas/bases.md#dip-bases-02-core-reads-the-device-time-zone-behind-the-evaluation-environments-back), [DIP-MDCORE-03](../areas/mdcore.md#dip-mdcore-03-new-block-identifiers-come-from-the-system-random-source), [DIP-PLUGIN-03](../areas/plugin.md#dip-plugin-03-platform-statics-in-logic-and-display-text-in-core), [DIP-RUNTIME-02](../areas/runtime.md#dip-runtime-02-clock-randomness-and-storage-are-called-inline). Systemic in 11 of 13 documents.

**Evidence.**
- 22 `Date()`/`Date.now` and 31 other clock reads in production Swift ([metrics.md](../metrics.md), pattern counts).
- The editor's one-second focus window and 1.5 s heading pin read uptime directly ([NativeMarkdownEditor.swift:104](../../../Sources/GraphiteUI/NativeMarkdownEditor.swift#L104), [:2273](../../../Sources/GraphiteUI/NativeMarkdownEditor.swift#L2273), [:2312](../../../Sources/GraphiteUI/NativeMarkdownEditor.swift#L2312)).
- Smoothing stamps strokes with `Date()`, and that date enters the stroke fingerprint the history and the saved PDF use ([InkSelection.swift:742](../../../Sources/GraphiteUI/InkSelection.swift#L742)).
- Core reads the device time zone behind the evaluation environment ([BaseDateSupport.swift:234-238](../../../Sources/GraphiteCore/BaseDateSupport.swift#L234-L238)), and the environment defaults to it and to `.now` ([BaseEvaluator.swift:10](../../../Sources/GraphiteCore/BaseEvaluator.swift#L10)).
- The index's 30-day cleanup reads `Date.now` ([VaultIndex.swift:240](../../../Sources/GraphiteIndex/VaultIndex.swift#L240)); place memory reads `Date()` ([WorkspacePlaces.swift:32](../../../Sources/GraphiteUI/WorkspacePlaces.swift#L32)).
- Block identifiers written into notes come from `randomElement()` in an unbounded loop ([NoteBlocks.swift:271-277](../../../Sources/GraphiteCore/NoteBlocks.swift#L271-L277)); persisted leaf identifiers in the runtime start with `Date.now()` ([community-plugin-runtime-workspace.js:18](../../../Sources/GraphiteUI/Resources/CommunityPluginRuntime/community-plugin-runtime-workspace.js#L18)).

**Cost.** Timing rules (focus window, heading pin, autosave, external-change debounce, interruption length, gesture windows, the 1.5 s live-view rule) are testable only by waiting in real time, which is why hosted tests sleep 173 times (CC-ARCH-09); `date.toString()` and `date.format()` can name different days in one Bases formula (DIP-BASES-02); identifiers persisted in notes and tab layouts cannot be pinned by a test (DIP-MDCORE-03, DIP-RUNTIME-02).

**Shared fix direction.** One injected clock value (wall time, uptime and a sleep primitive) in `AppEnvironment`; decisions take `now`, `calendar` and a `RandomNumberGenerator` as parameters with no default; the live clock is the only reader of the system clock. `pastedImageStem(date:)`, `autosaveDelay(afterSaveTaking:)`, `PencilActivityState` and `MacPastedAttachment.attachments(on:now:)` already have this shape. Rule DIP 8.

### 2.5 Features reach the file system, the network and platform singletons from logic and views

**What it is.** Views, UI models and Core helpers call `FileManager.default`, `Data(contentsOf:)`, `URLSession.shared`, `UIApplication.shared`, `UIDevice.current` or `UIPasteboard.general` themselves, outside `VaultStore` and outside any adapter, so vault reads skip coordination and failure paths cannot be substituted.

**Where.** [DIP-READING-01](../areas/reading.md#dip-reading-01-the-reading-builder-and-image-cache-construct-their-own-file-services), [DIP-BASES-01](../areas/bases.md#dip-bases-01-the-ui-model-performs-file-system-io-and-builds-its-own-collaborators), [DIP-BASES-04](../areas/bases.md#dip-bases-04-cover-and-image-downloads-use-the-shared-url-session-with-cookies), [DIP-CANVAS-03](../areas/canvas.md#dip-canvas-03-core-reads-plugin-settings-files-directly-as-untyped-dictionaries), [DIP-LECTURE-02](../areas/lecture.md#dip-lecture-02-recording-and-recovery-call-filemanagerdefault-and-application-support-directly), [DIP-VOICE-04](../areas/voice.md#dip-voice-04-the-cache-uses-the-wall-clock-and-the-file-system-directly-and-its-actor-is-untested), [DIP-EDITOR-02](../areas/editor.md#dip-editor-02-ui-types-construct-file-readers-and-depend-on-the-application-root), [DIP-EDITOR-03](../areas/editor.md#dip-editor-03-logic-reads-the-platform-clock-devices-and-application-objects-directly), [DIP-READING-04](../areas/reading.md#dip-reading-04-platform-singletons-and-static-mutable-caches-in-view-logic), [DIP-PLUGIN-03](../areas/plugin.md#dip-plugin-03-platform-statics-in-logic-and-display-text-in-core), [DIP-VAULT-02](../areas/vault.md#dip-vault-02-the-indexs-cache-folder-is-chosen-inside-the-database-type). Systemic in READING, BASES, CANVAS, LECTURE, VOICE, EDITOR, PLUGIN, VAULT.

**Evidence.**
- 190 `FileManager.default` lines in production Swift ([metrics.md](../metrics.md)); 21 of them in `RecordingController.swift` (DIP-LECTURE-02).
- Core hard-codes an Application Support folder through the default file manager ([RecordingRecovery.swift:52-57](../../../Sources/GraphiteCore/RecordingRecovery.swift#L52-L57)) and reads plugin settings files into `[String: Any]` by URL ([PlacedNote.swift:34-51](../../../Sources/GraphiteCore/PlacedNote.swift#L34-L51)).
- Card covers and `image()` URLs from note properties download through the shared, cookie-carrying session ([BaseValueViews.swift:441-452](../../../Sources/GraphiteUI/BaseValueViews.swift#L441-L452)), while map tiles use a hardened ephemeral session (DIP-BASES-04).

**Cost.** The reading view reads embedded notes without a coordinated read (DIP-READING-01); a Bases link tap asks `fileExists` synchronously on the main thread of a cloud-backed vault (DIP-BASES-01); opening a base with web covers sends the shared cookie jar to any host a note names (DIP-BASES-04); the recovery paths that keep "the only copy of a lecture" are tested by changing real permissions (DIP-LECTURE-02); workspace tests write their indexes into the real Caches folder (DIP-VAULT-02).

**Shared fix direction.** File and network access live in storage and network adapters (`VaultStore`, `IndexLocation`, `RecordingStore`, `HTTPDownloading`, `BaseRemoteImageSession`) built by the composition root; the policy part becomes a pure function over bytes (`propertyNames(geocodingSettings:mapViewSettings:)`); platform capabilities reach logic as values (`openExternalLink`, a device idiom, a pasteboard). Rules DIP 9, DIP 10, DIP 11.

### 2.6 Dependency direction: domain code knows presentation, adapters own vocabulary, production ships test and measurement code

**What it is.** Smaller inversions of the layer order: Core returns English sentences and depends on a reading-view type for a fence rule; plain value types live in adapter modules so the UI preferences import the index and PDF layers; a PDF registry names the workspace type; the runtime's `Vault` calls up into `MetadataCache`; one page-wide prototype patch; benchmark screens and test hooks ship in production types.

**Where.** [DIP-MDCORE-02](../areas/mdcore.md#dip-mdcore-02-domain-code-produces-user-visible-english), [DIP-MDCORE-04](../areas/mdcore.md#dip-mdcore-04-editor-styling-and-highlighting-depend-on-the-reading-view-type-for-a-fence-rule), [DIP-PLUGIN-03](../areas/plugin.md#dip-plugin-03-platform-statics-in-logic-and-display-text-in-core), [DIP-ARCH-05](../cross-cutting/architecture.md#dip-arch-05-plain-value-types-live-in-adapter-modules-so-the-ui-preferences-import-the-index-and-apple-adapters), [DIP-LECTURE-01](../areas/lecture.md#dip-lecture-01-feature-code-reaches-singletons-and-static-mutable-state), [DIP-RUNTIME-01](../areas/runtime.md#dip-runtime-01-domain-classes-reach-the-host-channel-and-the-application-through-globals), [DIP-RUNTIME-03](../areas/runtime.md#dip-runtime-03-one-platform-prototype-is-patched-for-the-whole-page), [DIP-VOICE-05](../areas/voice.md#dip-voice-05-the-measuring-tool-ships-in-the-production-module-and-the-app-entry-point), [DIP-INK-06](../areas/ink.md#dip-ink-06-test-hooks-live-in-production-types). Systemic in MDCORE, PLUGIN, ARCH, LECTURE, RUNTIME, VOICE, INK.

**Evidence.**
- `GraphitePreferences.swift` imports `GraphiteIndex` and imports `GraphiteApple` twice ([GraphitePreferences.swift:4-7](../../../Sources/GraphiteUI/GraphitePreferences.swift#L4-L7)).
- Core words a missing section for the user ([NoteBlocks.swift:263-267](../../../Sources/GraphiteCore/NoteBlocks.swift#L263-L267)).
- The embedded-PDF registry calls `WorkspaceModel.comparablePath` ([EmbeddedPDFViewer.swift:586](../../../Sources/GraphiteUI/EmbeddedPDFViewer.swift#L586)).
- The runtime replaces `EventTarget.prototype.addEventListener` for every object of the page ([community-plugin-runtime-reading.js:58-67](../../../Sources/GraphiteUI/Resources/CommunityPluginRuntime/community-plugin-runtime-reading.js#L58-L67)).
- The app entry point chooses a benchmark screen by launch argument inside production code ([GraphiteApp.swift:24](../../../App/GraphiteApp.swift#L24)).

**Cost.** Lower than 2.1–2.5: a preferences or settings module cannot be built without the database and PDFKit layers, which blocks the feature-module split (DIP-ARCH-05); user text in Core cannot be localised (DIP-MDCORE-02); plugins see Graphite's attribute and every attribute write counts as a block change (DIP-RUNTIME-03); device-measurement code and its switch ship to users (DIP-VOICE-05).

**Shared fix direction.** Value types without framework types move into Core; Core returns facts and one presenter words them; a registry that needs path comparison gets it from Core (`VaultLocation`), not from the workspace; runtime classes receive a narrow host channel and listen to vault events instead of calling up; the benchmark moves to its own target and launch modes become compositions chosen once at the root. Rules DIP 12, DIP 13, DIP 14, DIP 16.

## 6. Rules for new code

Starting-set rules kept here: "one composition root constructs adapters", "no default argument constructs an I/O dependency", "no singletons, static mutable state or service locators", "platform APIs only behind ports owned by the consuming layer", "one injected clock", "no consumer takes the application root", "one owner per persisted key", "fakes, not flags", "unsafe escapes only in one allow-listed file". Sharpened by the findings: semantic fallbacks in defaults are banned with I/O defaults (DIP-BASES-03); `static let` holding a mutable container counts as mutable static state (Corrections, item 1); an injected instance must be the only one used (DIP-INK-01); defaults are never a message channel (DIP-ARCH-04); hot paths take preferences as values (DIP-INK-03). Dropped as a separate rule: "capability interfaces have at most ~7 members" is folded into DIP 11 so that it applies only where a protocol is justified, as RULES.md requires.

**DIP 1 — The app target is the only composition root.** Every adapter that touches disk, `UserDefaults`, the network, WebKit, AVFoundation, PencilKit's shared state, the keychain or the clock must be constructed in `GraphiteApp.init` (through one `AppEnvironment`) or in a factory the environment owns; models, sessions and views must receive it through their initializer or a SwiftUI `@Environment` entry.
- *Check:* grep outside `App/` and the environment file for `= VaultStore(`, `VaultMonitor(`, `WKWebViewConfiguration(`, `CommunityPluginHost(`, `RecordingController(`, `GraphitePreferences(`, `VaultLibrary(`; reject `@State private var … = SomeModel()` where `SomeModel` owns any of these.
- *Answers:* DIP-ARCH-01, DIP-SHELL-01, DIP-PLUGIN-01, DIP-READING-01, DIP-EDITOR-02, DIP-BASES-01, DIP-VAULT-01, DIP-VAULT-02.

**DIP 2 — No default argument chooses a dependency or a semantic fallback.** A parameter of type `UserDefaults`, `URLSession`, `AtomicFileWriter`, `FileManager`, a speech, capture, storage or provider protocol, or a clock must have no default value, and an optional dependency must never be replaced by a different implementation inside the callee.
- *Check:* script regex `(UserDefaults|URLSession|AtomicFileWriter|FileManager|Clock|Storage|Provider|Speaking|Source)[^=,)]*=\s*` over `Sources/**` must return 0; review rejects `?? SomeDefaultImplementation(` on a dependency (`provider ?? BaseInMemoryRecordProvider`, `writer ?? AtomicFileWriter()`).
- *Answers:* DIP-PLUGIN-02, DIP-LECTURE-03, DIP-VOICE-02, DIP-INK-04, DIP-BASES-03, DIP-ARCH-01.

**DIP 3 — No singleton, service locator or mutable static in feature, model, view or Core code.** `static let shared`, static stored service references, `static var`, `static weak var` and `static let` holding a mutable container (`NSCache`, `Mutex`, a lock, a dictionary box) must not be added; process-wide services must live in `AppEnvironment`. Exceptions, each declared in one allow-listed file with a comment stating why it is safe: immutable constants, stateless delegates (`PDFPictureDrawingDelegate`), and bounded memoization of system-derived values (font family names, date formatters).
- *Check:* script regex `static\s+(weak\s+)?var\s+\w+\s*(:[^{]*)?(=[^{]*)?$` and `static\s+let\s+\w+\s*(:[^=]*)?=\s*(Mutex|NSCache|OSAllocatedUnfairLock|\w+\(\))` and `static\s+let\s+shared\b` must match only the allow-list file.
- *Answers:* DIP-ARCH-02, DIP-INK-02, DIP-SHELL-04, DIP-EDITOR-01, DIP-READING-02, DIP-READING-04, DIP-CANVAS-02, DIP-LECTURE-01, DIP-VOICE-01, DIP-VOICE-03, DIP-MDCORE-01.

**DIP 4 — A collaborator that is passed in is the only one used.** A type that receives an instance (through `init`, a parameter or `@Environment`) must read, observe and post notifications on that instance, never on a global of the same type; notification observers must name the injected object.
- *Check:* in review, every `addObserver(forName:object:)` names a stored or injected property, not `Type.shared`; grep `\.shared\b` in a file that also stores a property of the same type returns 0.
- *Answers:* DIP-INK-01, DIP-LECTURE-01.

**DIP 5 — Every persisted device key has one typed declaration and one store.** A `UserDefaults` key must be declared once in the `DeviceStateKey` registry with its exact name, value type, default, encoding, scope (global or per vault) and version, and must be read and written only through a `DeviceStateStore` over an injected `UserDefaults`; `@AppStorage` is allowed only with the registry's key and default; per-vault keys must be enumerable so a vault's removal deletes all of them.
- *Check:* grep `UserDefaults\.standard` outside the environment file, `@AppStorage\("` (string literal) and `"Graphite[A-Z]\w*"` literals outside the registry must return 0; a golden test reads every registry key with its legacy literal.
- *Answers:* DIP-ARCH-03, DIP-SHELL-02, DIP-SHELL-03, DIP-READING-03, DIP-CANVAS-01, DIP-INK-03, DIP-PLUGIN-01, DIP-VOICE-02.

**DIP 6 — Persisted state is never a message channel.** A command or model must change what a view shows by calling an intent method on the view's model (`showInspectorPanel(.graph)`, `show(panel:)`); only the owner of a persisted choice writes its key, and no code observes `UserDefaults.didChangeNotification`.
- *Check:* grep `UserDefaults\.didChangeNotification` returns 0; in review, a defaults write whose only reader is a view in another file is rejected.
- *Answers:* DIP-ARCH-04, DIP-SHELL-03, DIP-INK-03.

**DIP 7 — Touch, drawing and layout code takes preferences as values.** Code that runs per touch, per stroke, per frame or per layout pass must receive preferences as a value (for example `PencilPreferences`) that its owner observes once, and must not read `UserDefaults` or any store itself.
- *Check:* grep `UserDefaults|\.stored\b|isOn\(` inside `touchesBegan|touchesMoved|draw\(|layoutSubviews|hitTest|gestureRecognizer` bodies returns 0; pure deciders take the value as a parameter, as `PalmRejection.isHandResting` does.
- *Answers:* DIP-INK-03, DIP-ARCH-04.

**DIP 8 — Time, time zone and randomness come from one injected source.** Logic must take `now` (wall time or uptime), a `Calendar` and a `RandomNumberGenerator` as parameters or from an injected clock, with no default value; only the live clock adapter reads `Date()`, `.now`, `ContinuousClock.now`, `systemUptime`, `TimeZone.current`, `Calendar.current`, `randomElement()` without a generator, `Math.random()` or JavaScript `Date.now()`.
- *Check:* script regex `Date\(\)|Date\.now|=\s*\.now\b|ContinuousClock\.now|systemUptime|TimeZone\.current|Calendar\.current|randomElement\(\)|Math\.random\(|Date\.now\(\)` over `Sources/**` must match only the clock adapter files.
- *Answers:* DIP-SHELL-05, DIP-EDITOR-03, DIP-INK-05, DIP-LECTURE-04, DIP-CANVAS-04, DIP-VOICE-04, DIP-VAULT-01, DIP-BASES-01, DIP-BASES-02, DIP-MDCORE-03, DIP-PLUGIN-03, DIP-RUNTIME-02.

**DIP 9 — File and network I/O lives only in adapters; vault files are read only through the vault store.** Views, view models and Core policy must not call `FileManager`, `Data(contentsOf:)`, `FileHandle`, `URLSession` or `JSONSerialization` on files; a vault file must be read through `VaultStore` (coordinated, path-validated); a policy that decides from file content must take the bytes as a parameter; remote images and plugin downloads go through an injected, ephemeral session.
- *Check:* grep `FileManager\.default|Data\(contentsOf:|URLSession\.shared` in files that declare a `View`, an `@Observable` model or live in `GraphiteCore` must return 0 once `VaultStore` and the recovery folders leave Core (SRP-ARCH-03).
- *Answers:* DIP-READING-01, DIP-BASES-01, DIP-BASES-04, DIP-CANVAS-03, DIP-LECTURE-02, DIP-EDITOR-02, DIP-VOICE-04, DIP-PLUGIN-02.

**DIP 10 — Platform singletons stay at the edge.** `UIApplication.shared`, `NSWorkspace.shared`, `UIDevice.current`, `UIScreen.main`, `NSScreen.main` and `UIPasteboard.general` must be read only in platform adapters or in the top-level view that turns them into values; models, coordinators and drawing code receive a capability (`openExternalLink`, a device idiom, a pasteboard).
- *Check:* grep those six names outside the adapter and root-view files returns 0.
- *Answers:* DIP-EDITOR-03, DIP-READING-04, DIP-PLUGIN-03, DIP-INK-06.

**DIP 11 — A port is a protocol only when substitution is real, and every implementation runs one contract suite.** A protocol must have two production implementations or a stated test need it cannot meet otherwise (network, camera, model, keychain, file-provider versions), state that reason on its declaration, have at most about 7 members, be declared by the consuming module, and have one shared contract test suite that the production adapter and the fake (in the test-support target) both run. A single capability is a closure or a struct of closures, not a protocol.
- *Check:* a new `protocol` in review has ≥ 2 conformers (one may be a fake in `GraphiteTestSupport`), a "why" doc comment, ≤ 7 requirements, and a `…ContractTests` class instantiated for each conformer.
- *Answers:* DIP-PLUGIN-02, DIP-LECTURE-02, DIP-BASES-03, DIP-VOICE-04, DIP-RUNTIME-01.

**DIP 12 — Every cache and long-lived shared object has an owner that reaches it for cleanup.** A cache must be an instance created by the composition root or a feature model, bounded by a named limit, and its owner must conform to the release-memory and vault-close duties so the coordinator reaches it without naming the feature.
- *Check:* every `NSCache` or dictionary cache is a stored instance property of a type that conforms to the memory-release protocol; grep `NSCache<` outside such types returns 0.
- *Answers:* DIP-EDITOR-01, DIP-READING-02, DIP-CANVAS-02, DIP-MDCORE-01, DIP-ARCH-02.

**DIP 13 — Dependencies point inward: Core owns values, adapters and features depend on it.** Plain value types (no framework types) must live in `GraphiteCore`; an adapter module must not own vocabulary that UI preferences use; a feature type must not name `WorkspaceModel` or another feature's type for a shared rule (take it from Core); Core must not depend on a reading-view or UI type for a syntax rule.
- *Check:* `import GraphiteIndex` or `import GraphiteApple` in a preferences or settings file is rejected; grep `WorkspaceModel\.` outside the shell module returns 0; Core's `import` list stays Foundation, CoreGraphics, Markdown, Yams, CryptoKit, zlib, Synchronization.
- *Answers:* DIP-ARCH-05, DIP-MDCORE-04, DIP-LECTURE-01, DIP-EDITOR-02.

**DIP 14 — Domain code returns facts; one presenter words them.** Core, Index and Apple code must return typed facts (`.missingSection(subpath:note:)`, `title: String?`) and must not build user-visible sentences or display names.
- *Check:* grep for string literals with spaces returned from `public static func`/`var displayName` in `GraphiteCore` returns 0 outside the error-presenter catalogue.
- *Answers:* DIP-MDCORE-02, DIP-PLUGIN-03.

**DIP 15 — Test hooks and measuring tools do not ship; launch modes are compositions.** Test-only accessors, settable statics for tests and benchmark screens must live in the test-support target or a separate benchmark target; a launch mode (app, voice benchmark, hosted tests) must be parsed once in the composition root and select a different `AppEnvironment`, never a flag read inside production views.
- *Check:* grep `for tests|tests set|isRequested` in `Sources/**` returns 0; `GraphiteApp.body` builds one root from the environment.
- *Answers:* DIP-INK-06, DIP-VOICE-05, DIP-ARCH-01.

**DIP 16 — Runtime classes receive a narrow host channel; page-wide patches are scoped and named.** JavaScript classes that talk to Graphite must receive a `HostChannel` (or the narrower capability they use) through their constructor and must not read `runtime.hostBridge` or `runtime.app` themselves; a class must not call up into a layer that observes it (raise an event instead); a patch of a platform prototype must live in one file named for it, apply only to the elements that need it, and record why event delegation does not work.
- *Check:* grep `hostBridge\.|runtime\.app\b` inside class bodies of `community-plugin-runtime-*.js` returns 0 outside the composition file; grep `\.prototype\.\w+\s*=` matches only the named patch file.
- *Answers:* DIP-RUNTIME-01, DIP-RUNTIME-03, DIP-RUNTIME-02.

**DIP 17 — Tests build production types through the same initializers, with isolated dependencies.** A test must construct the type under test with a private `UserDefaults(suiteName:)`, a temporary folder, a fake clock and fakes from the test-support target, and must never read or write `UserDefaults.standard`, the real Caches or Application Support folder, or the keychain.
- *Check:* grep `UserDefaults\.standard|cachesDirectory|applicationSupportDirectory|SecItem` over `Tests/**` and `App/Tests/**` returns 0 (today: 26 and 72 `UserDefaults.standard` lines, CC-ARCH-09).
- *Answers:* DIP-SHELL-01, DIP-CANVAS-01, DIP-INK-03, DIP-PLUGIN-01, DIP-VOICE-02, DIP-VAULT-02.
