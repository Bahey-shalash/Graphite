## 1. Summary

**What the area does.** INK turns Apple Pencil input into ordinary files and edits them again. Three layers:

- **Core (pure):** the versioned re-editing record `DrawingPayload` with its paper/background vocabulary and limits, the PNG container `GraphitePNG` (private `grPK` chunk, visible-content digest), `ShapeRecognizer`, `HandwritingTidying` and `PictureRotation`.
- **Apple (format adapters):** `DrawingFileService` composes the visible file (PNG through the streaming `BandedPNGEncoder`, SVG through `SVGDrawingFile`, PDF through `PDFDrawingFile`, which is outside this scope) and verifies it reads back; `StrokeOutliner`/`PencilStrokeSampler` turn PencilKit strokes into filled outlines; `PencilDrawingChange` is the diff-based undo step; `EvenHighlighter`, `PencilShapes`, `PictureEditing`, `DrawingPictures` are PencilKit/ImageIO helpers.
- **UI:** `HistoryCanvasView` (the `PKCanvasView` subclass every canvas uses), the drawing editor (`DrawingEditor`, `DrawingCanvasController`, `InfiniteCanvasView`), Graphite's lasso (`InkSelectionController`, `LassoAreaCapture`, `LassoPasteboard`), the laser pointer, palm rejection, hold-to-shape, the fixed tool bar (`PencilToolbox`, `PencilToolbar`, `PencilToolButtons`, options, Pencil gestures), the floating palette (`PencilToolPalette`), the picture/selection frame (`SelectionFrameView`), drafts (`DrawingEditorDraftStore`) and drawing on images (`WorkspaceImageDrawing`).

**The three biggest problems.**

1. **The canvas classes are aggregates.** `HistoryCanvasView` carries history recording, tool binding (fixed bar vs. palette), the even-highlighter stand-in and its live band, hold-to-shape, a static footprint cache, the render cover, finger-stroke take-back and three lazily created tool controllers behind three booleans ([HistoryCanvasView.swift:14-761](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L14-L761)). `InfiniteCanvasView` adds 27 more stored properties ([DrawingEditor.swift:823-862](../../../Sources/GraphiteUI/DrawingEditor.swift#L823-L862)). Every PDF page and the drawing editor run through this class; its file has 16 commits, tied with `DrawingEditor.swift` for the most in the area.
2. **Global mutable tool state.** `PencilToolbox.shared` ([PencilToolbox.swift:195](../../../Sources/GraphiteUI/PencilToolbox.swift#L195)), the three static booleans of `PaletteInkSelection` ([InkSelection.swift:84-110](../../../Sources/GraphiteUI/InkSelection.swift#L84-L110)), `PencilActivity`'s statics ([PalmRejection.swift:129-136](../../../Sources/GraphiteUI/PalmRejection.swift#L129-L136)), the static footprint cache ([HistoryCanvasView.swift:414](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L414)) and the static "controller with selection" ([InkSelection.swift:144](../../../Sources/GraphiteUI/InkSelection.swift#L144)) make every canvas depend on process-wide state; hosted tests mutate `UserDefaults.standard` to drive them ([PencilToolsTests.swift:165](../../../App/Tests/PencilToolsTests.swift#L165)).
3. **Two real defects and fragile ordering.** A recovered draft reopens with the request's original background, not the one the user chose (BUG-INK-01); the shape shown while holding the Pencil is recognized in zoomed canvas coordinates from touch points, but the stroke is replaced by a second recognition in drawing coordinates, so at any zoom other than 1 the preview and the result disagree (BUG-INK-02). Correctness also rests on a 1-second "arriving stroke" window, a 0.5-second render cover and four `DispatchQueue.main.async` hops ([HistoryCanvasView.swift:321-331](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L321-L331), [HistoryCanvasView.swift:611](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L611)).

**The three best parts.**

1. **The file formats are defensive and self-verifying.** `GraphitePNG` parses without copying, checks every CRC, separates its digest by a domain string and still accepts the legacy digest ([GraphitePNG.swift:69-131](../../../Sources/GraphiteCore/GraphitePNG.swift#L69-L131)); `DrawingPayload` refuses a property list with too many objects before decoding ([DrawingPayload.swift:356-374](../../../Sources/GraphiteCore/DrawingPayload.swift#L356-L374)) and a record whose content does not match its version ([DrawingPayload.swift:319-333](../../../Sources/GraphiteCore/DrawingPayload.swift#L319-L333)); `DrawingFileService.fileData` reads every encoded file back, and checks a PNG with an independent decoder, before it returns bytes ([DrawingFileService.swift:163-180](../../../Sources/GraphiteApple/DrawingFileService.swift#L163-L180)).
2. **Pure, tested geometry.** `ShapeRecognizer` (iterative RDP, named thresholds, 20+ tests), `HandwritingTidying`, `PictureRotation`, `PencilActivityState` (explicit times in, a decision out, [PalmRejection.swift:19-92](../../../Sources/GraphiteUI/PalmRejection.swift#L19-L92)) and `SelectionFrameView`'s static `moved`/`cropped`/`resized`/`handleCenter` ([SelectionFrameView.swift:452-625](../../../Sources/GraphiteUI/SelectionFrameView.swift#L452-L625)) are decide-only code with tests.
3. **The document-owned undo history.** `PencilDrawingChange` stores only the strokes a change touched, refuses to apply to a drawing it did not produce, and rebuilds strokes so PencilKit redraws them ([PencilDrawingChange.swift:29-98](../../../Sources/GraphiteApple/PencilDrawingChange.swift#L29-L98)); the canvas's own undo manager records nothing ([HistoryCanvasView.swift:19-24](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L19-L24)).

**Calls that cross responsibilities (a split must keep them):**
- `drawingAfterShapeRecognition` runs the even-highlighter rewrite first, then remembers the footprint, then the shape replacement, then the render cover ([HistoryCanvasView.swift:338-365](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L338-L365)): a shape made from an even highlight is even.
- `showDrawingFromHistory` ends PencilKit's lasso and Graphite's selection before it sets `recordedDrawing` and then `drawing` ([HistoryCanvasView.swift:41-47](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L41-L47)).
- `strokeTouchDidRest` removes the even band, and `strokeTouchDidMove` brings it back when the shape is withdrawn ([HistoryCanvasView.swift:479](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L479), [HistoryCanvasView.swift:495](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L495)); `coverUntilRendered` hides the band ([HistoryCanvasView.swift:630](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L630)).
- The dragged-shape stroke passes through `evenHighlighterStroke` ([HistoryCanvasView.swift:527](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L527)).
- `selectsInk`/`pointsWithLaser`/`pointsToRead` setters all call `applyDrawingEnabled`, which also reads `isDrawingSuspended` ([HistoryCanvasView.swift:237-239](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L237-L239)).

**Lifecycle and ordering rules it relies on:**
- `recordedDrawing` must be assigned before `drawing` whenever the canvas shows a drawing the history produced; the owner's delegate then sees no difference ([HistoryCanvasView.swift:45-46](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L45-L46), relied on at [DrawingEditor.swift:1367-1369](../../../Sources/GraphiteUI/DrawingEditor.swift#L1367-L1369)).
- `drawingAfterShapeRecognition` must be asked exactly once per reported change: it consumes `arrivingStroke` ([HistoryCanvasView.swift:340-343](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L340-L343)).
- A canvas-made drawing must be reported within 1 s of `expect(.isMadeByCanvas)` ([HistoryCanvasView.swift:323](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L323)); otherwise the next real stroke is treated as canvas-made.
- `stopFollowing` must run before the canvas is released ([DrawingEditor.swift:1300](../../../Sources/GraphiteUI/DrawingEditor.swift#L1300)); the UserDefaults observer is never removed (CC-INK-06).
- Gesture recognizers are added on first `didMoveToWindow` ([HistoryCanvasView.swift:462-467](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L462-L467)).

**Verdict:** Weak single responsibility. **Proposed split** (the class keeps being the `PKCanvasView` subclass; collaborators are owned by it, not protocols):
- `HistoryCanvasView` keeps history (`recordedDrawing`, `showDrawingFromHistory`, `setDrawingMadeByCanvas`, `showWithoutRecording`), input view, and a `mode: CanvasMode` enum (`drawing`, `selectingInk`, `pointingWithLaser`, `pointingToRead`) replacing the three booleans.
- `CanvasToolBinding` (fixed tool vs. palette, `PaletteToolCorrection`, `retakeChosenTool`, `toolForDrawing`).
- `EvenHighlightStroke` (preference, stand-in color, `evenHighlighterStroke`, band layer and follower).
- `HeldShapeTracker` (hold recognizer callbacks, `heldShape`, preview layer, `drawingSwitchedOffTime`), with an injected `StrokeFootprintStore` instance instead of the static dictionary.
- `ReportedStrokeExpectation` (the `arrivingStroke` value and its expiry) returned to the caller of `drawingAfterShapeRecognition` rather than read from a field.
- `RenderCover` (snapshot, mask, expiry).
- `HandStrokeTakeBack` (pending hand touches, next-turn check).

#### SRP-INK-01 `HistoryCanvasView` is one class for nine jobs that every canvas inherits
- **Severity:** High

## 5. Defects and latent bugs

#### BUG-INK-01 A recovered drawing draft reopens with the original background, losing the paper colour the user chose
- **Trigger:** In the drawing editor the user picks another background (for example "Yellow Background"), draws, and leaves the app; the system ends the app; the user reopens the vault and the editor comes back from the draft.
- **Path:**
  1. The picker writes `canvasController.background`, which marks a change ([DrawingEditor.swift:291-293](../../../Sources/GraphiteUI/DrawingEditor.swift#L291-L293), [DrawingEditor.swift:468-474](../../../Sources/GraphiteUI/DrawingEditor.swift#L468-L474)).
  2. On `.background` the editor preserves `currentContent`, whose background is the controller's ([DrawingEditor.swift:201-203](../../../Sources/GraphiteUI/DrawingEditor.swift#L201-L203), [DrawingEditor.swift:324-327](../../../Sources/GraphiteUI/DrawingEditor.swift#L324-L327)).
  3. The root view builds the draft description from the *request* ([GraphiteRootView.swift:185](../../../Sources/GraphiteUI/GraphiteRootView.swift#L185)); `DrawingEditorDraft.init` stores `background = request.background` ([DrawingEditorDraftStore.swift:35](../../../Sources/GraphiteUI/DrawingEditorDraftStore.swift#L35)); the draft file's payload holds the chosen background ([DrawingFileService.swift:211](../../../Sources/GraphiteApple/DrawingFileService.swift#L211)).
  4. On recovery `editorRequest(inVaultAt:)` passes `background: draft.background` while it takes paper and pictures from the payload ([DrawingEditorDraftStore.swift:57-59](../../../Sources/GraphiteUI/DrawingEditorDraftStore.swift#L57-L59)), called from [GraphiteRootView.swift:576](../../../Sources/GraphiteUI/GraphiteRootView.swift#L576).
  5. The editor seeds the controller from the request's background ([DrawingEditor.swift:126-127](../../../Sources/GraphiteUI/DrawingEditor.swift#L126-L127)).
- **Effect:** the recovered drawing shows, and Insert/Done saves, the original background; the paper pattern and pictures the user set are kept, the background is silently reverted.
- **Platforms / reach:** iPad and iPhone (the draft path is UIKit-only); the normal recovery path.
- **Confidence:** Traced.

#### BUG-INK-02 The shape shown while holding the Pencil is not what the stroke becomes when the canvas is zoomed
- **Trigger:** Draw a small round or straight stroke and hold at its end on a canvas whose zoom is not 1: a PDF page zoomed past fit (rendering scale 1.5 to 3, [GraphitePDFView.swift:670-674](../../../Sources/GraphiteUI/GraphitePDFView.swift#L670-L674), applied as the canvas zoom at [GraphitePDFView.swift:710-719](../../../Sources/GraphiteUI/GraphitePDFView.swift#L710-L719)), or the drawing editor, whose zoom is the view width over 760 points and up to four times that ([DrawingEditor.swift:1096-1102](../../../Sources/GraphiteUI/DrawingEditor.swift#L1096-L1102), [DrawingEditor.swift:31](../../../Sources/GraphiteUI/DrawingEditor.swift#L31)).
- **Path:**
  1. `StrokeHoldRecognizer` collects `touch.location(in: view)` and coalesced samples, in the canvas's zoomed content coordinates ([StrokeHold.swift:91](../../../Sources/GraphiteUI/StrokeHold.swift#L91), [StrokeHold.swift:97-99](../../../Sources/GraphiteUI/StrokeHold.swift#L97-L99)); it is installed on the canvas itself ([HistoryCanvasView.swift:464](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L464)).
  2. On rest, `strokeTouchDidRest` recognizes those points and shows the preview ([HistoryCanvasView.swift:473-483](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L473-L483)).
  3. On lift it only records the expectation ([HistoryCanvasView.swift:516-518](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L516-L518)).
  4. When PencilKit reports the stroke, `drawingAfterShapeRecognition` removes the preview and calls `PencilShapes.replacingNewStroke` ([HistoryCanvasView.swift:345-355](../../../Sources/GraphiteUI/HistoryCanvasView.swift#L345-L355)), which recognizes again from PencilKit's interpolated points in *drawing* coordinates ([PencilShapes.swift:20-25](../../../Sources/GraphiteApple/PencilShapes.swift#L20-L25)).
  5. `ShapeRecognizer` rejects strokes under 16 points and arcs under 32 points of chord, in absolute points ([ShapeRecognizer.swift:229-232](../../../Sources/GraphiteCore/ShapeRecognizer.swift#L229-L232), [ShapeRecognizer.swift:264-267](../../../Sources/GraphiteCore/ShapeRecognizer.swift#L264-L267)). At rendering scale 3 a circle 10 page points across has a bounding diagonal of about 42 canvas points (previewed) and about 14 page points (rejected).
- **Effect:** zoomed in, the circle or line the user saw while holding vanishes at the lift and the wobbly stroke stays (or a different shape appears near a threshold); zoomed out (an iPhone fits the 760-point canvas at about one half), strokes the shape tool would recognize cannot be held into a shape. The hosted test passes identical coordinates to both paths ([PencilToolsTests.swift:200-214](../../../App/Tests/PencilToolsTests.swift#L200-L214)), so it does not cover this.
- **Platforms / reach:** iPad and iPhone (UIKit canvases); normal path whenever the canvas zoom is not 1.
- **Confidence:** Partly traced: every step was read; whether a given stroke crosses a threshold depends on its geometry, which was not executed.

#### BUG-INK-03 Two quick taps on "Rotate Image Right" turn a drawing's picture once and leave two undo steps
- **Trigger:** While arranging pictures in the drawing editor, tap Rotate Image Right twice before the first re-encode finishes.
- **Path:** each tap runs `runPictureChange` in its own `Task` ([DrawingEditor.swift:228](../../../Sources/GraphiteUI/DrawingEditor.swift#L228), [DrawingEditor.swift:387-391](../../../Sources/GraphiteUI/DrawingEditor.swift#L387-L391)); `rotateSelectedPictureRight` reads the picture before awaiting the detached re-encode ([DrawingEditor.swift:600-603](../../../Sources/GraphiteUI/DrawingEditor.swift#L600-L603)); both tasks therefore turn the original bytes once and compute the frame from the original ([DrawingEditor.swift:604-607](../../../Sources/GraphiteUI/DrawingEditor.swift#L604-L607)); each `replacePictures` registers a step ([DrawingEditor.swift:728-741](../../../Sources/GraphiteUI/DrawingEditor.swift#L728-L741)). - **Effect:** the picture is turned a quarter instead of a half; the first Undo shows no change. A move of the picture during the re-encode is overwritten the same way.
- **Platforms / reach:** iPad and iPhone; normal path, timing-dependent.
- **Confidence:** Partly traced: the window is the decode and re-encode time of the stored picture (up to twice the canvas width in pixels, [DrawingPictures.swift:35](../../../Sources/GraphiteApple/DrawingPictures.swift#L35)), not measured.

#### BUG-INK-04 Drawing on a note's image says the note "no longer embeds" the image when the note only changed meanwhile
- **Trigger:** Draw on an image from a note and save while the note's text changes during the save (typing in a split view, an autosaved edit, an external change applied).
